Компьютер использует Little-endian порядок байтов и при записи в память число переворачивается, младший байт встаёт в начало


В кодировке UTF-8 один символ может быть закодирован несколькими байтами, поэтому количество символов может отличаться от количества байт.


A: 41
А: D0-90

Байты для компьютера просто набор символов, которые интерпретировать можно по разному и без указания конкретной кодировки(в нашем случае UTF-8) компьютер не знает как интерпретировать тот или иной символ. UTF-8 так сказать правило, которым пользуется компьютер для интерпретации символов.
