# Практическая работа №3
## Цель
## 1. Представление числа в байтах
Для выбранных значений:
- 01-00-00-00
- 00-01-00-00
- 00-00-01-00
Тип данных int всегда занимает 4 байта в независимости от числа. Каждое умножение на 256 значащий байт сдвигается на 1 позицию в сторону старшего байта.
## 2. Порядок байтов
- True
- число `305419896`;
- 78-56-34-12
- Компьютер использует Little-endian порядок байтов и при записи в память число переворачивается, младший байт встаёт в начало
## 3. Текст и UTF-8
Сравнение:
- `ABC`; 3 символа; 3 байта
- `Привет`; 6 символов; 12 байт
В кодировке UTF-8 один символ может быть закодирован несколькими байтами, поэтому количество символов может отличаться от количества байт.

## 4. Английская и русская букваСравнить:
- `A`; Английская - 1 байт
- `А`; Русская - 2 байта
Это разные символы несмотря на внешние сходства, у них разное положение в таблице Unicode.
## 5. Обратное преобразование
Показать, что:
- строку можно превратить в байты и восстановить обратно через Encoding.UTF8.
- число можно превратить в байты и восстановить обратно через BitConverter.
